# 运镜与编排

每一段片子写成一个时间轴文件（`src/s<段号>.js`）。导演页按时间轴逐帧推进：镜头怎么动、光标点哪里、哪里压暗聚焦、哪里出标注，全部写在里面。

本文的函数名以 `templates/` 里的实现为准，模板改名时同步改本文。

## 一、骨架：旁白在前，动作锚在词上

时间轴以旁白为骨架：

- `say()` 按顺序排句子。
- `L.at('词')` 取这句念到某个词的时刻，镜头、点击、聚焦、标注都锚在这些时刻上。
- 改了旁白、换了音色，句子时长变了，动作会跟着平移，不用重排。

```js
const a2 = S.say('a2', 0.8)                 // 上一句结束后留 0.8 秒，开始念 a2
S.tap(a2.t + 0.2, BTN('.todo', '查看'))     // 句首后 0.2 秒点开
S.focus(a2.at('左边是原文'), 2.4, '.parallel')
S.callout(a2.at('右边'), 2.6, '.parallel-head', '原文 · <em>逐段中文</em>')
```

- `L.at(词)` 取这个词开始念的时刻，`L.at(词, 1)` 取这个词念完的时刻。
  - 时刻来自配音后的逐字强制对齐（`audio/vo/<id>.json` 里每个字的起止时间），精确到毫秒级。
  - 对齐数据缺失时退回按字数比例估算，并报警告。这种估算在长句、带停顿的句子里会偏差半秒以上，不能当作常态。
- 词不在句子里会直接报错，所以改旁白后时间轴跑一遍就能发现锚词失效。
- 换音色、改语速、重新合成某一句之后，重新对齐这一句，动作自动跟着走。
- 每段可以设 `gapPad`，所有句间留白统一加长，用来整体放慢节奏。

## 二、编排动作

| 动作 | 写法 | 用途 |
|---|---|---|
| 说一句 | `say(id, 留白, { feature })` | 排一句旁白，返回这句的起止与 `at()`；`feature` 写功能清单里的编号，进交付的时间索引 |
| 镜头 | `cam(t, 时长, 目标, 选项)` | 推拉摇移到某个区域或全景 |
| 聚焦 | `focus(t, 时长, 目标, { pad })` | 目标之外压暗，可以同时聚焦几个目标 |
| 标注 | `callout(t, 时长, 目标, 文字, { side, off })` | 引线加一句短标注，`<em>` 高亮关键词 |
| 点击 | `tap(t, 目标, { d, at, js })` | 光标移过去，在 t 时刻按下 |
| 滚动 | `scroll(t, 时长, 容器, 目标或位置, { offset })` | 应用内滚动到某个元素 |
| 打字 | `type(t, 文字, 每秒字数)` | 逐字输入，返回打完的时刻 |
| 按键 | `key(t, 键名)` | 回车、Tab 等 |
| 逐行显露 | `reveal(t, 时长, 目标)` | 代替模型的流式输出，保证每次渲染一样 |
| 上传 | `upload(t, 文件框选择器, 文件路径)` | 真实上传一个文件 |
| 切页 | `nav(t, 地址, 就绪选择器)` | 跳转并等就绪信号 |
| 模块名 | `lower(t, 名称, 副标)` | 左下角浮出模块名 |
| 卡片 | `card({ kind, ... })` | 章节卡、片头卡、示意图卡、实物飞入卡、空镜 |
| 卡点 | `cue(t, 类型)` | 给配乐标节点 |
| 淡入淡出 | `fade(t, 时长, 从, 到)` | 段首段尾黑场 |
| 停住 | `hold(t, 时长, 理由)` | 标明这段画面有意静止，交付检查不报长时间静止 |
| 脚本动作 | `act({ t, js })` | 以上都不够时直接在应用里执行脚本 |

**目标的写法**

- 选择器字符串：`'.stats-grid'`
- 带文字和序号：`{ sel: '.menu-item', text: '客户池', nth: 0 }`
- 几个目标的并集：`['.attachments', '.history']`
- 所有匹配元素合成一个框：`{ sel: 'tr.hot', all: true }`

聚焦、标注、点击都先校验目标存在、可见、尺寸不为零，不满足就报警告。

## 三、镜头语言

### 三档景别

| 景别 | 缩放 | 用在 |
|---|---|---|
| 全景 | 1.0 | 切页、看整体布局、段首段尾 |
| 区域 | 1.25 到 1.45 | 一块面板、一张表、一个表单 |
| 特写 | 1.55 到 1.8 | 一个字段、一个出处、一个标签 |

- 实际用得最多的是全景 1.0 和区域 1.3 左右。特写一句最多一次，用在“这个数字从哪来”“这一处缺了什么”这种要观众看清的地方。
- 手机页面套手机外框后，景别整体收一档。

### 镜头怎么动

- **禁令**：Agent 容易把“有电影感”理解成镜头一直推，这是成片最常见的毛病。下面三条不能破：
  - 不连续推镜：一次推近完成后，下一次镜头运动之前必须停住，停留不少于 1.2 秒。
  - 每次操作最多推近一次：点一个按钮、看一个字段，推一次就够，不在同一处来回推拉。
  - 不做匀速长推：缓推（`drift`）只用在停住的画面上，幅度不超过 0.03。
- **提前到位**：镜头比句子早 0.3 到 0.8 秒开始动，念到要讲的东西时画面已经到位。
- **时长**：一次推拉 1.1 到 1.8 秒。
- **次数**：一句话里最多动两次。
- **缓推**：到位后加 `drift` 约 0.02 的缓推，画面不死，也不会晕。
- **路径**：推拉和平移同时发生时，引擎按平滑缩放路径走，先拉远一点再推到新位置，比直线插值自然；`rho` 调这个弧度。
- **切页**：先拉回全景，再点侧栏或菜单，模块名随后从左下角浮出。观众能看到“去了哪里”。
- **不要**：镜头大幅移动的同时应用内也大幅滚动，会晕；两者错开至少半秒。

### 聚焦与标注

- **顺序**：镜头先到，再聚焦，再出标注。
- **聚焦**：锚在讲到它的那个词上，持续到这句讲完再多留 0.2 到 1 秒。`pad` 2 到 6 像素，紧贴目标。一句话里聚焦不超过两个区域。
- **标注**：
  - 一句不超过 14 个字，关键数字或结论用 `<em>`，停留 2.4 到 2.8 秒。
  - 放在目标旁边，不遮住正在讲的内容；`side` 选空白多的一侧，`off` 微调。
- **关键操作**：确认、发出、提交之前，先聚焦被操作的内容，旁白点明对象，再点击。
- **后排看不清界面小字**：界面上的字一般 12 到 16 像素，推到 1.8 倍也只有 20 多像素，会场后排看不清。要观众记住的数字或结论，用标注写出来，或者推成特写；交付检查会提醒没有标注的聚焦。

### 光标与点击

- 光标移动 0.8 到 1.0 秒，在锚词时刻按下。
- 点击后 0.3 秒内镜头不动，让观众看到界面反应。
- 切页或打开抽屉后，光标暂时隐藏，下次要点时再出现。
- 分段按钮、页签、示例标签这类控件，导演页里真点偶尔不生效，`tap` 默认用脚本同步补点一次；其他控件需要时加 `{ js: true }`。
- 手机页面用指尖光标代替箭头。

### 打字与生成

- 打字每秒 9 到 14 个字。短句快，长句慢一点，看起来像真人在输入。
- 打字期间旁白可以继续；下一句旁白等打完再开始：`S.say(id, Math.max(0.5, 打完时刻 - S.now + 0.3))`。
- 模型生成的内容用回放缓存出结果，再用逐行显露呈现，不依赖真实的流式速度。

## 四、段落结构

### 段首

1. 黑场淡入 0.6 秒。
2. 章节卡从第 0 帧开始遮盖，停留约 3.4 秒：
   - 背景是空镜视频（来自生视频工具，或代码绘制的推拉）
   - 上面是段号、中英文段名、副标
3. 同时打一个 `cue('chapter')` 给配乐。
4. 章节卡遮着的时候完成切页，镜头从全景 1.1 倍带一点下移开始缓推。
5. 第 4 秒左右开始第一句旁白。

### 段中

- 每句一个画面时刻，按第三节的镜头语言写。
- 需要换模块时按切页的写法：先全景，再点菜单，再浮出模块名。
- 讲到接入方式、部署结构这类看不见的东西，用示意图卡；讲到名片、纸质单据这类实物，用实物飞入卡。

### 段尾

- 最后一句念完后留 0.8 秒，再黑场淡出 1.4 秒。
- 播放方式是“段间讲解”时，淡出后多留 1 到 2 秒静默，给讲者接话。

### 段间接力

- 后一段从前一段结束时的应用状态开始，状态存成 `build/state_<段>.json`。
- 每段可以单独渲染、单独重做。

## 五、给配乐的节点

配乐卡点用的节点从时间轴自动导出（`build/export_tl.mjs`），分四级：

| 级别 | 来源 | 配乐里怎么处理 |
|---|---|---|
| 一级 | 章节卡、片头、片尾 | 滚奏、吊镲、低频冲击，乐段在这里换 |
| 二级 | 关键操作：确认、发出、生成 | 低频下潜或重音，前面的律动空半拍 |
| 三级 | 普通点击、显露、示意图亮起 | 短促的提示音或轻打击 |
| 四级 | 旁白起句 | 只换和声，不加打击 |

关键操作用 `cue(t, 'key')` 显式标出；其余由导出脚本按动作类型自动分级。

## 六、写完一段之后

1. 跑检查帧：`node build/check.mjs <段> 10,20,30`（不写秒数就每 5 秒一帧），拼成联系表 `frames/chk_<段>.png`，引擎警告汇总在表头和 `frames/issues_<段>.json`。Agent 自己逐帧看：镜头到位没有、聚焦圈对没有、标注有没有遮挡、界面是不是就绪状态。
2. 看引擎警告：目标找不到、点击落在可视区外、锚词不在句子里、锚词没有对齐数据、两次推镜之间没有停住。全部清零再往下走。
3. 检查阶段顺带录好模型接口的回放缓存，存好段末状态。
4. 全片出完跑交付前检查 `node build/qa.mjs`，见模板 README 的“交付前检查”。

## 七、节奏参考

| 参数 | 常用值 |
|---|---|
| 句间留白 | 0.3 到 0.8 秒；整体放慢时 `gapPad` 加 0.4 |
| 镜头提前量 | 0.3 到 0.8 秒 |
| 镜头运动 | 1.1 到 1.8 秒 |
| 推近之后的停留 | 不少于 1.2 秒 |
| 光标移动 | 0.8 到 1.0 秒 |
| 应用内滚动 | 1.0 到 1.4 秒 |
| 标注停留 | 2.4 到 2.8 秒 |
| 打字 | 每秒 9 到 14 字 |
| 章节卡 | 约 3.4 秒，第 4 秒开始旁白 |
| 段尾 | 留 0.8 秒，淡出 1.4 秒 |
