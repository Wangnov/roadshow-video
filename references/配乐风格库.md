# 配乐风格库

配乐由 Agent 按每部片子的时间轴现场作曲：写 MIDI，用 FluidSynth 加开源的真实乐器音色库渲染，少量合成音色用 numpy 补；混入旁白与音效，出每段的成品音轨。

本文记录用过的风格、各自的编法和用户的评价，供挑风格和作曲时参考。

## 一、总则

1. **按场合挑风格，不重复上一部。** profile 里记着这位用户每部片子用过的风格族，下一部换一族；场合只适合同一族时，至少换调性、速度和主奏乐器。
2. **跟着画面卡点。** 从时间轴导出节点（见 `运镜与编排.md` 第五节），在节点之间微调速度，让重要节点落在小节强拍上。
3. **段落跟着片子走。** 章节卡和模块切换处换乐段；每段结尾提前约两秒落主和弦，片尾长音和混响多留三秒。
4. **给旁白让路。** 旁白出现时配乐闪避，参数见第四节。
5. **审听以用户为准。** 风格和卡点在审核点 2 的试片里一起听。需要第二意见时用配对盲测（甲乙随机），不用绝对打分。

## 二、风格族

| 风格族 | 包含的风格 | 听感 |
|---|---|---|
| 管弦铺底 | 轻柔政务风、电影感 | 钢琴与弦乐为主，舒缓、开阔、克制 |
| 流行商务 | 国内商务宣传片风 | 钢琴律动、弦乐跳弓、流行鼓组与电贝司，积极、有推进感 |

用户对同一族里的两种风格会听成“一样的风格”：管弦铺底族里的电影感，被评价为和轻柔政务风太像。所以轮换以族为单位。

模板里有两个作曲脚本，一部片子选一个，各段都用它：

- `audio/score.py`：流行商务风格族（国内商务宣传片风）。
- `audio/score_orch.py`：管弦铺底风格族（轻柔政务风）。

各段用法见 `templates/film/README.md`。

## 三、风格条目

### 轻柔政务风（管弦铺底族）

- **适用**：政务、国企汇报。
- **用户评价**：试片后认可，没有改过。
- **速度与调性**：82 BPM，D 大调。
- **编制**：
  - 钢琴、弦乐铺底、大提琴与低音提琴、竖琴与钢片琴点缀、定音鼓，用音色库渲染。
  - 拨弦、低频、轻打击、上扬与重音用 numpy 合成。
- **段落**：模块切换处换乐段，模块名浮出的时刻对齐到最近的强拍。乐段之间轮换四种和声与配器：钢琴琶音、拨弦推进、轻心跳鼓、弦乐抬高八度。全片结尾落 Dmaj9。
- **混音**：旁白段配乐闪避 7 dB；片中插入真实录音的段落，配乐再让 6 dB。
- **模板实现**：`audio/score_orch.py`。作曲、配器、混音的参数照原样搬进来；结尾主和弦落在段尾黑场淡出处；关键操作给钢片琴两个音加一记轻低频。片中插入真实录音这一路，时间轴还没有对应写法，没有搬。

### 电影感（管弦铺底族）

- **适用**：投资路演的片头片尾，或需要开阔感的段落。
- **用户评价**：作为第一稿被换掉，原因是和轻柔政务风听起来是同一路。
- **编制**：
  - 片头、收尾：慢弦乐、钢琴、竖琴、钢片琴、圆号、定音鼓，开阔、落定。
  - 日常操作段：钢琴琶音、马林巴、弦乐拨奏、低音提琴、沙锤与轻底鼓，轻快。
  - 管理层段：大提琴旋律、圆号铺底、慢弦乐、钢琴，沉稳。
- **卡点**：章节卡处定音鼓与镲的滚奏渐强。
- **混音**：旁白段配乐闪避 9 dB。

### 国内商务宣传片风（流行商务族）

- **适用**：企业客户提案、国企、偏商业的路演；也可以用在政务片里，和轻柔政务风错开。
- **用户评价**：用户点名要的风格，“国内商务配乐常用的”。改了四稿，第四稿在配对盲测里胜出并采用。
- **和声**：流行进行，比如 I-V-vi-IV、IV-V-iii-vi、vi-IV-I-V；情绪下沉处用 vi-iii-IV-I。
- **编制**：
  - **钢琴**：分解和弦，按强弱拍给力度，5 到 10 毫秒的人性化错位，放在中音区，跨度一个八度多。
  - **弦乐**：中提琴与大提琴长音铺底，每小节有起伏。小提琴只在片头片尾高潮进，不上 C5。
  - **节奏声部**：拨弦或跳弓做律动，流行鼓组，电贝司。
  - **点缀**：颤音琴，放在中高音区并压低。
  - **片头、管理层段、收尾**：加圆号与定音鼓。
- **各段参数**：

  | 段落性质 | 速度 | 钢琴 | 鼓 | 律动声部 | 铜管与定音鼓 |
  |---|---|---|---|---|---|
  | 片头 | 92 | 琶音 | 半速 | 无 | 有 |
  | 日常操作 | 116 | 阿尔贝蒂低音 | 流行 | 拨弦 | 无 |
  | 现场、高能 | 122 | 脉冲 | 流行 | 跳弓 | 无 |
  | 办公、平稳 | 104 | 琶音 | 流行 | 拨弦 | 无 |
  | 管理层 | 100 | 脉冲 | 半速 | 跳弓 | 有 |
  | 收尾 | 96 | 琶音 | 半速 | 跳弓 | 有 |

  各段调性错开，相邻段落差一个全音左右。
- **卡点四级**：
  - **一级**（章节、片头片尾）：管弦小军鼓滚奏一拍半，反向镲，吊镲，圆号八度，42 到 85 Hz 的低频冲击。
  - **二级**（确认发出这类关键操作）：低频下潜、钢琴低八度、大鼓。不打断律动。
  - **三级**（普通界面操作）：短促的反吸噪声、颤音琴提示音、轻大鼓。
  - **四级**（旁白起句）：只换和声。
  - 只有一级落点前留空白；能量每小节最多降一级，不断崖式抽空。
- **四稿里去掉的东西**：
  - 每拍砸下的柱式和弦：太吵。
  - 带延迟的闷音电吉他：被听成塑料合成器琶音。
  - 亮的扫频：廉价感。
  - 每个落点都滚奏：太满。

### 不进候选的风格

- **科技电子风**：不做。科技与互联网客户也从上面两个风格族里挑。

- **爵士、波萨诺瓦**：
  - **用法**：七、九、十三和弦与 ii-V 进行，罗兹电钢琴、尼龙弦吉他、低音提琴、刷子鼓、弱音小号。
  - **用户评价**：“不够档次，而且怪怪的”。
  - **结论**：放在路演里显得不够正式，不进候选。

## 四、混音

| 项目 | 参数 |
|---|---|
| 旁白时的闪避 | 低频声部（贝司、鼓、铺底、低音弦乐）8 dB，高频声部（钢琴、中提琴、拨弦、提示音、铜管）13 dB，800 Hz 到 3 kHz 再额外压 3 dB |
| 旁白处理 | 去齿音，两级压缩 |
| 总线 | 低频托 2.5 dB，6.5 kHz 松 2 dB |
| 现场环境声 | 压到约 -40 dB，只留 350 Hz 到 4 kHz，挖掉 1.5 到 1.8 kHz 的人声频段，旁白时再让 9 dB |
| 音效 | 比配乐总线低约 4 dB，关键操作的音效可以略高 |
| 总响度 | -16 LUFS，峰值不超过 -1 dBTP |

### 基础库里没有的音效

先看代码合成的或基础库里相近的能不能顶上。画面里确实有特定的实物声音（扫码枪、打印机、刷卡、开柜门这类），再去 Freesound 找，接口按 `服务与工具文档.md` 第四节现场查。

Agent 听不到这些声音，挑的时候靠听过的人留下的信号：

- **搜索**：按画面动作写英文关键词。取前几页按相关度排的结果，再按下载量重排；直接按下载量排序，跑题的热门声音（枪声、环境声）会挤到前面。
- **下载量与评分**：同样合适时选下载多的；评分人数比平均分可信，四点四分三百八十人评，强过四点九分六人评。
- **描述**：上传者写的声源和录音设备最接近试听。写着用某款录音机录的、声源说得清楚的，可信；写着手机自带麦克风、用嘴模仿的，是低保真。描述里的声源和画面对不上就不用，再热门也不用。
- **先量再用**：热门不等于合适，一个“咚”可能是三秒的电影低频。看时长，再用 ffmpeg 量起音前的空白、能量集中在哪、尾巴多长；起音前的空白要裁掉，不然卡点会晚半拍。
- **许可**：CC0 直接用；CC BY 可以用，在 `CREDITS.md` 署名；CC BY-NC 和 Sampling+ 不用，路演是商业用途。
- **给用户听**：候选不止一个、又拿不准时，用 `scripts/audition.mjs` 出本地试听页让用户挑。
- **入库**：选定的放进共用音效目录，文件名带来源和编号（比如 `fs_123456.wav`），以后的片子直接用；来源、作者、许可写进 `CREDITS.md`。
